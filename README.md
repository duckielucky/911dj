# 911.COM

一个只有一个 HTML 文件的本地音乐播放器。深色霓虹风格，六个独立设计的页面，
无需安装、无需账号、无需联网 —— 你的文件不会离开这台电脑。

## 两种运行方式

这一份文件既是本地播放器，也是 911dj.com 的整站源码 —— 打开时会自动判断：

| 模式 | 何时生效 | 歌曲存在哪 |
| --- | --- | --- |
| **本地模式** | 双击 `index.html`，或用下面的启动脚本 | 这台电脑的浏览器数据库里 |
| **服务器模式** | 部署到 911dj.com 之后 | Cloudflare R2，登录后任何设备共用一个曲库 |

部署到域名的完整步骤见 **[DEPLOY.md](DEPLOY.md)**。
服务器模式下整站有密码，右上角会多一个退出登录按钮。

## 两种打开方式

**推荐 —— 双击 `Open 911.com.command`**
它会启动一个很小的本地服务器并打开播放器。曲库、重命名、播放次数、收藏和自定义顺序
都会保留到下次打开。听歌时保持那个小的终端窗口开着；关掉它（或按 Ctrl-C）即停止。
*第一次运行 macOS 可能会拦截：右键点击文件 → 打开 → 打开。*

**快速 —— 双击 `index.html`**
功能一样，但浏览器会禁止以这种方式打开的文件使用存储，所以关闭标签页后曲库会清空。
处于这种模式时，应用会提示你。

## 页面

| 页面 | 内容 |
| --- | --- |
| **首页** | 主视觉、快捷入口，以及以封面卡片呈现的完整曲库。顶部有排序标签；拖动卡片上的手柄可自定义顺序。 |
| **最新音乐** | 按添加时间排序，最新一首放在聚光位。 |
| **热门榜单** | 按你自己的播放次数排名 —— 前三名领奖台 + 带播放进度条的编号列表。 |
| **音乐人** | 曲库中的每位歌手一个头像卡片。点击任意一位进入他的专属页面。 |
| **我的收藏** | 所有点过红心的歌曲，可一键播放或随机播放。 |
| **关于我们** | 工作原理、支持格式、存储方式、全部快捷键，以及清空曲库。 |
| **全屏播放** | 模糊背景上的大图封面 + 接下来播放队列。按 **F** 或点击播放条上的歌名。 |

## 使用

- **添加歌曲** —— 「上传 MP3」、文件夹按钮，或直接把文件/文件夹拖到页面上。
- 封面、标题、歌手和专辑都来自每个文件的 ID3 标签。没有内嵌封面的歌曲会自动生成
  渐变封面，并把标题排在上面。
- **排序** —— 在首页选中「全部 · 自定顺序」后，拖动封面上的手柄（⠿）。
- **卡片菜单（⋯）** —— 播放、收藏、查看音乐人、重命名、分享、保存副本、从曲库移除。
  重命名只改变这里的显示方式，不会修改文件本身。
- **红心**收藏与**播放次数**会随使用累积，二者共同驱动热门榜单、我的收藏，
  以及卡片角标（热门 / 已收藏 / 最新）。
- 支持格式：mp3、m4a、aac、wav、flac、ogg、opus、aiff。

## 快捷键

| 按键 | 功能 |
| --- | --- |
| 空格 | 播放 / 暂停 |
| ← / → | 快退 / 快进 10 秒 |
| ↑ / ↓ | 音量 |
| N / P | 下一首 / 上一首 |
| S | 随机播放开 / 关 |
| R | 循环：关 → 全部 → 单曲 |
| F | 全屏播放 |
| M | 静音 |
| / | 搜索 |
| Esc | 关闭全屏 / 弹窗 |

随机播放会围绕当前正在播放的歌曲重新打乱队列，当前这首不会中断。
媒体键和 macOS 的「正在播放」小组件同样可用。

## 说明

- **本地模式**：歌曲只保存在这台电脑、这个浏览器里，不会上传到任何地方；
  每个浏览器各自保存一份曲库（Chrome 和 Safari 不共享）；清除网站数据会清空曲库。
- **服务器模式**：歌曲存在你自己的 Cloudflare R2 里，只有知道密码的人能访问。
- 文件夹里的 `functions/` 和 `wrangler.toml` 只在部署时用到，本地播放不需要它们。
